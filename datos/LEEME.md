# Plantilla de grupos

`plantilla-grupos.csv` es la plantilla para la base de datos inicial de grupos (unos 200). Se abre con Excel o Numbers.

Cada fila es un grupo. Las columnas son:

| Columna | Qué poner | ¿Obligatoria? |
|---|---|---|
| `nombre` | Nombre del grupo, escrito tal como lo escribe el grupo | Sí |
| `ciudad` | Ciudad de origen | Sí |
| `comunidad` | Comunidad autónoma | Sí |
| `año_inicio` | Año en que empezó el grupo (4 cifras) | No |
| `estilos` | Uno o varios de la lista de abajo, separados por ` / ` | Sí |
| `bio_corta` | 1 o 2 frases que describan al grupo | No |
| `bandcamp` | Enlace completo a su Bandcamp | No |
| `spotify` | Enlace completo a su perfil de Spotify | No |
| `apple_music` | Enlace completo a su perfil de Apple Music | No |
| `youtube` | Enlace completo a su canal de YouTube | No |
| `web` | Enlace completo a su web propia | No |

## Estilos admitidos

`post-rock`, `prog`, `post-metal`, `math rock`, `stoner`, `shoegaze`, `doom`, `sludge`, `heavy`

## Reglas

- **Nada privado.** El repositorio es público: no incluir emails de contacto, teléfonos, notas internas ni prioridades. Si se guardan, que sea en una copia privada fuera del repositorio.
- **Nada de redes sociales.** No incluir enlaces a Facebook, Instagram ni X.
- La fila "Grupo de Ejemplo" solo muestra cómo rellenar la plantilla: hay que borrarla.
- Al guardar desde Excel, elegir el formato **CSV UTF-8** para que no se estropeen las tildes y las eñes.
