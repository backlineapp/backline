Claves de los avisos

Esta página crea las claves de los avisos dentro de tu navegador. No envía nada a ningún sitio y no guarda nada: si la cierras, las claves desaparecen.

Hazlo una sola vez. Si un día vuelves a crear claves y las cambias en Supabase, todos los móviles dejarán de recibir avisos hasta que los vuelvan a activar.

1 · Para el SQL Editor de Supabase

Copia este bloque y ejecútalo en SQL Editor → New query → Run. Guarda en la caja fuerte de Supabase la clave pública y la clave de las tareas.
